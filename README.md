# Airfields resource pack

The built resource pack for [Airfields](https://airfieldsmc.com), served from here because Minecraft clients (and Minehut) download it from `raw.githubusercontent.com`.

| File | What it is |
| --- | --- |
| `airfields-pack.zip` | The pack the server sends to Java players |
| `airfields-pack.sha1` | Its SHA-1, which the server reads to know when it changed |

Everything here is published automatically from a private repository. Don't open pull requests: they'd be overwritten.
