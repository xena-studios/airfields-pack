# Airfields resource pack

**The resource pack Airfields players download when they join.**

The built resource pack for [Airfields](https://airfieldsmc.com), a Minecraft server by [Xena Studios](https://xenastudios.co) (winter sky-mining PvP on Java & Bedrock). It's served from here because Minecraft clients (and Minehut) download packs from a public URL; there's nothing to do with it by hand.

| File | What it is |
| --- | --- |
| `airfields-pack.zip` | The newest pack |
| `airfields-pack.sha1` | Its SHA-1, and which copy in `packs/` it is, which the server reads to know when it changed |
| `packs/<sha1>.zip` | Each published pack under its own hash; the newest 10 are kept |
| `skins/<name>.png` | The skins the server's NPCs wear, for the current season |

## Contributing

Everything here is published by CI from Airfields' private repository, so pull requests would be overwritten. Problems with the pack go to the server's support, not an issue here.
